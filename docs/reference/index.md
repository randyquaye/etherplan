# CLI reference

Use [Commands](commands.md) to find a command by the state it reads or writes. [Environment variables](environment.md) lists the inputs the CLI reads from the process. Each command also has its own option help:

```sh
etherplan --help
etherplan plan --help
```

Run project commands from the directory containing `main.ethp`. For an install in your project's dev dependencies, prefix commands with `npx` as shown in the [quick start](../start/quickstart.md).
