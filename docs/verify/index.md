# Verify contracts

[Verify live contracts](existing-contracts.md) to compare code, immutables, and declared getters with the project. [Import an existing contract](import.md) records a reviewed deployment. [Creation proof](creation-proof.md) explains why matching bytecode alone may be insufficient. [Rebuilt artifacts](artifact-changes.md) covers changed build output for an existing deployment.

For constructors that create other contracts or depend on changing state, see [stateful constructors](../recovery/stateful-constructors.md). For an RPC replay failure, follow [RPC replay recovery](../recovery/rpc-replay.md); for a transaction that succeeded but could not be proved, follow [review and import](../recovery/review-and-import.md).
