# Getting started

Etherplan turns a project file and compiled Solidity artifacts into a reviewed plan for an EVM chain.

1. [How Etherplan works](overview.md): desired state, live observations, and local records.
2. [Install and prepare](install.md): Node.js, artifacts, RPC, and the CREATE2 factory.
3. [Quick start](quickstart.md): compile, validate, plan, apply, verify, and read addresses.

After the first run, use the [project reference](../project/index.md) or [command reference](../reference/index.md).
