# Deploy contracts

Use this path after writing [a project](../project/index.md):

1. [Validate and plan](validate-and-plan.md) without signing a transaction.
2. [Apply a plan](apply.md) and read the recorded addresses.
3. [Recover an interrupted apply](../recovery/index.md) with its state and journal.

See [Dependencies](../dependencies/index.md) for address and execution ordering. Use [fees and replacements](fees.md) when a transaction remains pending. [Parallel deployers](parallel.md) and [pipelining](pipeline.md) are optional execution modes. For shared recovery across runners, see [AWS CLI setup](../operations/aws-cli.md).
